# The app's name is Income Expense Tracker App

The project was renamed from its old name ("propertyledger" / "PropertyLedger")
on 2026-10-09. Never use the old name for anything new: no app names, package
names, file or folder names, branches, backups, copy, store fields, URLs or
console entries. Use `income-expense-tracker`, `incomeexpensetracker` or
"Income Expense Tracker App". Before typing an ID into any console or form,
check it for the old name.

The old name survives only where it cannot be changed, and nowhere else:
- the iOS bundle ID `com.trueorganichub.propertyledger` (Apple never allows a
  live App Store app's bundle ID to change; the Apple sign-in key uses it too);
- the Expo project slug `propertyledger` (Expo cannot rename a slug);
- the App Review demo login, whose email is on the old domain.

Android was never published, so its package is
`com.trueorganichub.incomeexpensetracker`.
